# Code of Conduct

This repository is a personal engineering memory and learning journey, maintained by a single author and used alongside AI agents. It is public-facing as a portfolio artifact, so the same baseline expectations apply here as to any professional repository:

- Be respectful and constructive in any issue, discussion, or pull request.
- Critique ideas and code, not people.
- Assume good faith.
- Harassment, discrimination, or personal attacks of any kind will not be tolerated and will result in the interaction being removed and the participant blocked.

To report a concern, open an issue or contact the maintainer directly via the profile linked in [`README.md`](README.md).
