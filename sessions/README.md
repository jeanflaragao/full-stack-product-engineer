# Sessions

One file per training/engineering session, named `day-NNN.md` (e.g. `day-036.md`), numbered sequentially from the start of the journey — not from the creation date of this repository.

Each session record should capture:

- **Objective** — what the session set out to do.
- **Context** — relevant state going in.
- **Work performed** — what actually happened.
- **Decisions** — any decisions made, including small ones not significant enough for a formal ADR.
- **Lessons** — anything worth extracting into `journey/lessons/`.
- **Open questions** — anything left unresolved.
- **Next steps** — what should happen next.

Historical sessions must never be silently rewritten. Corrections or follow-ups go in a new session entry, not an edit to a past one.
